# setup/ —— 安装与恢复脚本

| 脚本 | 用途 |
|---|---|
| **install.sh** | ★ 从 archlinux.iso 一键安装（系统 + niri 桌面）。见仓库根 README |
| **desktop-packages.txt** | 桌面二进制 pacman 清单（GPU 相关走 pacman） |
| **restore.sh** | 已装好系统的恢复（nix + home-manager + 全部应用） |
| **pacman-packages.txt** | 完整 pacman 包清单（含个体应用） |
| **update.sh** | 一键更新（flake 更新 + home-manager switch + pacman） |
| **migrate-daemon.fish** | 迁移辅助脚本 |

完整说明见仓库根目录 `README.md`。
